WhatsApp & Telegram Number Checker

Version 1.0.0 | Standalone Windows Desktop Software

1. Quick Start (No Setup Required)

  1. Double click WhatsApp_Telegram_Validator.exe to open the software.
  2. Link WhatsApp (Free): Click 🔗 Link WhatsApp (Scan QR) and scan the QR code once with your phone. Once connected, your badge displays 🟢 Linked & Ready!
  3. Choose Mode: Toggle 🟢 Live Verification Mode for real-time checks, or 🧪 Offline Demo Mode for local processing.
  4. Click Choose CSV / File... and select your lead list (you can test with the included sample_apollo_leads.csv).
  5. Select platforms: WhatsApp and Telegram.
  6. Click ▶ Start Validation.
  7. When completed, click 💾 Export Enriched CSV to save your results.

2. Key Features

  • Free WhatsApp Web Engine: Connect via QR code and validate real WhatsApp numbers with zero Meta Graph API fees or monthly token costs.
  • Full CSV Passthrough: Keeps all original columns (First Name, Company, Email, Apollo ID) and appends validation results to each row.
  • 0–100 Lead Quality Scoring: Evaluates carrier type and messaging presence to provide an instant composite deliverability rating.
  • Timezone & Business Hours: Detects local time and safe contact windows (Monday–Friday 9 AM – 6 PM in lead's timezone).
  • Google libphonenumber: E.164 standardization, carrier brand detection, and landline/VoIP filtering.
  • Telegram Premium: Detects active Telegram Premium subscribers.

3. Settings & API Configuration

Click the ⚙️ Settings button in the top right:

  • Free WhatsApp Engine: Scan QR code from the main window. No API setup required.
  • Offline Simulation Mode: Runs offline on your CPU with zero network calls. Ideal for quick demos and data formatting checks.
  • WhatsApp Cloud API (Optional): Enter your Meta Access Token and Phone Number ID if you prefer using the official Meta Cloud API.
  • Telegram MTProto (Optional): Enter your free Telegram API ID and Hash from my.telegram.org for direct live MTProto resolution with automated address-book cleanup.
